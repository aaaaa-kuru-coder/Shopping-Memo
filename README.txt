買い物メモ ローカル版 v2

【構成】
index.html
styles.css
app.js
images/egg.png

【使い方】
1. ZIPを展開します。
2. shopping_memo_local_v2 フォルダを丸ごとAndroidへコピーします。
3. index.html をブラウザで開きます。

【注意】
・index.htmlだけを単独で移動しないでください。
・外部通信はありません。
・データはブラウザのlocalStorageに保存されます。
・通常の<select><option>はAndroidで画像表示が安定しないため、画像付き選択肢を確実に表示できるカスタム選択UIにしています。
