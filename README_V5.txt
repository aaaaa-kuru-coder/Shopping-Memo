買い物メモ GitHub Pages / PWA版 v5

主な変更
--------
1. 品目アイコンを従来の約2倍（基本32×32px）で表示。
2. 同じ品目は1行にまとめ、「×2」のように数量表示。
3. 各行に「−」「＋」「✓」を追加。
   - − : 1個減らす。1個のときに押すと行を削除。
   - ＋ : 1個増やす。
   - ✓ : その品目をすべて買い終わったものとして行を削除。
4. 新規登録UIを「入力欄 + 追加」1本に統合。
5. 入力文字を含む候補を先頭へ移動し、青色で強調。
6. 候補ボタンをタップすると即1個追加。
7. 買い物リスト部分を、横罫線のノート風背景に変更。
8. v4以前の重複行は、v5起動時に数量へ自動統合。
9. items.json はユーザー提供版を採用。
10. items.json に将来 optional の "keywords": ["EXV", "オリーブ"] を追加すると、
    aliasやPG名以外でも候補検索できます。

items.json
----------
例:
"olive": {
  "alias": "オリーブオイル",
  "iconfile": "olive.png",
  "quick": true,
  "order": 13,
  "keywords": ["オリーブ", "油"]
}

keywords は省略可能です。

画像
----
items.json で iconfile を指定したPNGは images/ 配下へ置きます。
例:
images/milk.png
images/banana.png
images/egg.png
images/olive.png

このZIP内で元v4に存在していた画像は egg.png のみです。
items.json が参照していて画像ファイルがまだ無い場合でも、
壊れた画像マークを出さずテキストのみで動作するようにしています。

GitHub Pages更新
----------------
既存リポジトリへv5のファイルを上書きアップロードし、Commitしてください。
PWAのService Workerキャッシュ名をv5へ変更しているため、
通常は新しいHTML/CSS/JSへ更新されます。
反映が遅い場合は、Chromeで一度ページを再読み込みしてください。

保存データ
----------
買い物リストは引き続き localStorage にだけ保存します。
v4と同じ保存キーを維持しているので、既存リストを自動移行できます。
